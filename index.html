第一步：从您的 Google 表格复制

打开您的 Google 表格【安桑每日爆贴】，按快捷键 Ctrl + A 全选表格（或选中包含 B 列中文与 C 列葡语的数据行），按 Ctrl + C 复制。

第二步：粘贴到 GospelFlow

回到工作台，点击蓝色的 【📋 一键粘贴表格数据】 按钮（或直接在页面中按 Ctrl + V）。软件会自动提取 B 列中文、C 列葡语、D 列播放量，并自动跳过第 2、3 行空白行！

第三步：点击智能重组

点击中部的 【🚀 开始 AI 智能重组新文案】 按钮。本地 RTX 5060 的 Meta Llama 3.1 将自动理解每篇文案的属灵主题，把最合适的黄金启语（钩子）嫁接到同向见证主体上，杜绝逻辑崩塌。

第四步：一键复制回 Google 表格

生成完成后，点击绿色的 【📋 一键复制全部成品】 按钮。回到您的 Google 表格【成品】标签页，在第 2 行直接按 Ctrl + V，整张表工整入列！

如何打包发给团队成员？ 直接将本工具文件夹压缩为 .zip 压缩包发送给同事。无论是 Windows 还是 Mac 苹果电脑，解压后按下方指引配置一次模型，即可永久离线使用！
一、Windows 电脑配置步骤 (有独立显卡效果更佳) 双击 .bat 启动
1. 安装 Ollama 软件 点击下载 Windows 官方安装包

下载后双击运行 OllamaSetup.exe，按照默认提示一直下一步完成安装。

2. 下载 Meta Llama 3.1:8b 大模型 体积约 4.7 GB (仅需下载一次)

按键盘快捷键 Win + R，输入 cmd 回车打开黑色命令行，输入命令回车：

ollama run llama3.1:8b

下载完成后终端显示 >>> Send a message 即表示成功，直接关闭黑色命令行即可。

3. 启动 GospelFlow

在解压文件夹中，双击运行 启动工作台.bat，浏览器会自动打开并显示本地模型已就绪！

二、Mac 苹果电脑配置步骤 (支持 M1/M2/M3/M4 及 Intel Mac) 双击 .command 启动
1. 安装 Ollama for Mac 点击下载 Mac 官方安装包 (.zip)

下载解压后，将 Ollama.app 拖入“应用程序 (Applications)”并打开运行即可。

2. 在 Mac 终端拉取模型 统一内存加速，M芯片速度极快

按快捷键 Command + 空格 搜索并打开 终端 (Terminal)，粘贴运行：

ollama run llama3.1:8b

下载完成后终端显示 >>> Send a message 即可关闭终端。

3. 启动 GospelFlow

在解压文件夹中，双击运行 启动工作台_Mac.command，即会自动开启服务并弹出网页工作台！

备选：轻薄本无独显或希望直接使用云端引擎

若成员电脑性能有限，也可直接点击工作台右上角的【⚙️ 设置】，切换为 xAI Grok 或 Google Gemini 并填入 API Key 即可。
