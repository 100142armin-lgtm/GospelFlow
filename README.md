## 🌟 核心特色与设计准则

1. **类似 Google 表格的内置可编辑双工作表**：
   - 📋 **原始爆贴工作表 (输入区)**：A列序号自动产生，B列中文文案，C列葡语文案，D列播放量，E列备注。直接在 Google 表格中按 `Ctrl+A` 复制，在软件中按 `Ctrl+V` 一键批量填入，**自动跳过空行**！支持单元格双击自由修改、增删行。
   - 📋 **成品质检工作表 (输出区)**：生成中葡双语对照表，支持单单元格复制、整行复制，或点击**【一键复制全部成品】**，直接在 Google 表格按 `Ctrl+V` 即可带格式整表粘贴回【成品】表！
2. **AI 属灵语义深度理解（同向相融，严防搞笑话）**：
   - 拆解出：**① 黄金启语(钩子)**、**② 核心旷野与见证内容(主体)**、**③ 呼召回应与祝福(号召)**。
   - Meta Llama 3.1 先深度理解每篇文案的属灵主题（如：家庭婚姻、疾病医治、债务困境、清晨信心祝福等）。
   - **智能同向嫁接**：只有同向相通的启语与正文才会被重组嫁接，并自动润色口播过渡句，杜绝逻辑崩塌的滑稽组合。
   - **真实非洲葡语**：葡语直接从对应原爆贴提取真实原句进行拼装，并由 AI 补足转折连词，100% 传承原汁原味的受众表达习惯。
3. **支持 15 篇与 20 篇矩阵生成（智能分批）**：
   - 突破模型 Token 长度瓶颈，自动按 5 篇/批进行调度，生成稳定不截断，表格实时滚动刷新。
4. **智能排期日期自动顺延**：
   - 自动检测历史旧日期，推演为未来即将发布的排期（如 10月8日、10月8日~10日），中葡双语全自动校准。
5. **极简在线一键热更新**：
   - 页面右上角自动检测官方 GitHub 仓库更新，点击即可一键无感热替换代码，无需重新打包，数据永久保留。

## ⚡ 30 秒极速工作流

1. **启动**：
   - **Windows 成员（推荐纯静默零黑框）**：双击 **`启动工作台(无黑框).vbs`**（或双击 **`启动工作台.bat`**），**完全没有任何黑色控制台窗口**，像普通桌面软件一样直接唤起浏览器进入工作台！
   - **Mac 成员**：双击运行 **`启动工作台_Mac.command`**；
   - **退出/停止服务**：双击 **`停止服务.bat`** 或 **`停止服务(无黑框).vbs`** 即可一键安全停止后台服务。
2. **复制表格**：在您的 Google 表格【安桑每日爆贴】中按 `Ctrl+A` ➔ `Ctrl+C` 复制。
3. **一键粘贴**：回到 GospelFlow，点击蓝色的 **【📋 一键粘贴表格数据】**（或直接按 `Ctrl+V`），表格数据瞬间排号呈现！
4. **智能重组**：选择篇数与排期，点击 **【🚀 开始 AI 智能重组新文案】**。
5. **一键粘贴回 Google 表格**：点击绿色的 **【📋 一键复制全部成品】**，回到 Google 表格【成品】页按 `Ctrl+V`，工整入列！

## 📁 目录结构说明

- `index.html`：GospelFlow 双表格交互、语义重组与在线热更新前端核心。
- `server.py`：超轻量 Python 本地中继与更新代理引擎（纯标准库，零 pip 依赖）。
- `启动工作台(无黑框).vbs`：Windows 100% 纯静默无黑框启动脚本（推荐）。
- `启动工作台.bat`：Windows 快速启动入口（调用静默引擎后自动退出窗口）。
- `停止服务(无黑框).vbs`：Windows 一键静默安全退出服务。
- `停止服务.bat`：Windows 一键终止后台服务。
- `启动工作台_Mac.command`：Mac 苹果电脑一键双击启动脚本。
- `version.json`：版本与在线更新元数据。
- `README.md`：本说明文档。
